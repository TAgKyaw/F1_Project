About the Project

This platform is an end-to-end MLOps solution designed to analyze and predict Formula 1 race dynamics by leveraging historical data from the 2020 season to the 2024 season. The project is built with a multi-stage pipeline that transforms raw race results into actionable intelligence.

🛠️ Data Engineering

Automated Bronze to Gold layer pipeline ensuring data quality and schema standardization.

📊 Advanced Features

Rolling averages, reliability tracking, and custom consistency scores for deeper insights.

🤖 ML Predictions

Random Forest Regressor trained to predict finishing positions with high accuracy (MAE ~1.5).
